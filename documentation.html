GTA SA Online CLEO Compiler & Community Hub

Official Feature Documentation & User Manual

1. Introduction & Overview

The GTA SA Online CLEO Compiler & Community Hub is a web-based integrated development environment (IDE) and sharing platform built specifically for Grand Theft Auto modders. It allows users to write, lint, compile, and decompile CLEO scripts (.cs, .csa, .csi) directly from their browser—both on PC and mobile devices—without needing heavy desktop software like Sanny Builder.

2. GitHub Private Sync & Auto-Save Feature 🐙

One of the core features of the platform is direct integration with personal GitHub repositories, ensuring that your source codes and compiled outputs are securely backed up.

  • 🔑 Configuration: Users can link their GitHub account by generating a Personal Access Token (PAT) with repo scope permissions. The token and repository name are stored securely in your browser's local storage.
  • 📁 Auto-Creation: If the specified private repository does not exist on your GitHub account, the platform automatically creates it for you.
  • 💾 How Auto-Save Works: When enabled, any compiled script or source file is committed directly to your private repository in real-time. When you click Compile & Download, the backend compiles your code, triggers an automatic background commit via the GitHub Contents API, and downloads the file to your device.

3. Core IDE & Compiler Features

A. Advanced Monaco Code Editor

  • Syntax Highlighting: Custom Monarch token provider designed for CLEO syntax.
  • Real-Time GUI Linter: Automatically scans code for duplicate labels or missing jump references every 300ms.
  • Multi-Tab Interface: Work on multiple script files simultaneously with ease.

B. Multi-Game & Platform Support

Supports GTA San Andreas, GTA Vice City, and GTA III. Outputs include .cs for PC, along with .csa and .csi formats for Mobile devices.

C. Quick Templates & Snippets

Built-in template selector to instantly load common boilerplate scripts like Car Spawner, Teleport, and Godmode.

D. Custom Class Database & Advanced CLI Flags

Upload custom .db files to extend opcode support and toggle advanced compiler/decompiler flags directly from the UI.

4. Community Hub & Social Features 🚀

  • 🌐 Public Scripts Feed: A decentralized community space where global modders can share and discover creations.
  • 📸 Instant ImgBB Screenshot Integration: Automatic image uploads via the ImgBB API to display clean preview cards for mods.
  • 📥 Download Counter: Securely track script downloads through the platform registry.
  • 💬 Discussion Threads: Interactive comments section supporting GitHub avatars and thread owner controls.

5. Step-by-Step User Guide

Step 1: Writing & Compiling Code

Open the editor, write your script or select a template. Choose your target game/platform and click "Compile & Download". The system will process your script and optionally auto-commit it to GitHub.

Step 2: Publishing to the Community 🚀

Click the 🚀 Publish button in the header, fill in your details, attach your files and screenshot, and submit to share your work with the global modding community.
